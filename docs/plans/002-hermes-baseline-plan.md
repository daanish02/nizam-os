# Phase 2 Hermes Baseline — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grafana agent-usage panels live, Nazim (admin) Hermes profile running on Discord via LiteLLM, SAVE framework installed.

**Architecture:** Hermes auto-generates `~/.hermes/profiles/admin/config.yaml` via `admin setup`. The file is then symlinked into the repo (`config/admin-config.yaml`) and patched with `yq` — never overwritten wholesale. Per-profile secrets live in `secrets/admin.env` (plaintext, gitignored). One LiteLLM virtual key per agent profile (`sk-nizam-admin` for Phase 2).

**Tech Stack:** Hermes (system binary), LiteLLM Admin API, yq, bash.

## Before You Start

- Phase 1 must be complete: LiteLLM at `localhost:4000`, PostgreSQL running, `secrets/nizam-os.env` fully populated.
- Create the Discord server manually before anything else. The guide walks through this.
- Populate Phase 2 vars in `nizam-os.env` before running the transition script.

---

## Global Constraints

- Phase 2 is **Nazim (admin) only**. Other agent profiles come in later phases.
- Config SSOT: `config/admin-config.yaml` — committed. Auto-generated by Hermes, symlinked, then patched.
- Env SSOT: `secrets/admin.env` (gitignored).
- SSOT content for persona: `hermes/profiles/admin/SOUL.md` — committed.
- `allow_lazy_installs: false` — non-negotiable.
- `approvals.mode: manual` — non-negotiable.
- `redact_secrets: true` — non-negotiable.
- `discord.allowed_channels` — System category only: ALERTS, LOGS, ADMIN, SANDBOX.
- `cron_mode: manual` for admin.
- Terminal enabled with `command_allowlist` scoped to service restarts only (see Task 5).
- Primary model: `deepseek/deepseek-v4-flash` (no `openrouter/` prefix — LiteLLM wildcard adds it).
- `model.api_mode` must be `chat_completions` (underscore, not `chat/completions`).
- `config/litellm.yaml` must have `drop_params: true` — required for hermes → litellm → openrouter.
- LiteLLM key alias: `sk-nizam-admin`. One key per profile — never share across profiles.
- Never commit plaintext `secrets/admin.env`.
- All paths relative to `~/nizam-os/` unless stated.

### Task 3: `002-hermes.sh` — default gateway stop

**Files:**
- Create: `scripts/setup/002-hermes.sh`

This script is the Phase 2 transition point. Its sole job: stop the default gateway so it does not conflict with the admin profile gateway.

- [ ] **Step 1: Write `scripts/setup/002-hermes.sh`**

```bash
#!/usr/bin/env bash
# Phase 2 transition: stops the default Hermes gateway.
# Run after testing default gateway, before creating admin profile.
set -euo pipefail

BLD='\033[1m'; GRN='\033[32m'; CYN='\033[36m'; RST='\033[0m'

echo ""
printf "${BLD}${CYN}==> Stopping default Hermes gateway${RST}\n"
hermes gateway stop 2>/dev/null || true
printf "${GRN}  default gateway stopped${RST}\n"

printf "\n${BLD}Next:${RST} follow docs/guides/002-hermes-baseline-guide.md → Step 5 onwards\n"
```

```bash
chmod +x scripts/setup/002-hermes.sh
```

- [ ] **Step 2: Verify (requires default gateway running)**

```bash
hermes gateway status   # → running (before)
sudo bash scripts/setup/002-hermes.sh
hermes gateway status   # → stopped (after)
```

| Output tokens by agent (this month) | Bar chart | `nizam_llm_output_tokens_this_month` — legend: `{{key_alias}}` |

**Row D — Daily cost heatmap**

- Panel type: Calendar panel (`marcusolsson-calendar-panel`)

| Panel | Type | Query |

### Task 8: Sudoers — Nazim

**Runtime only:** `/etc/sudoers.d/admin-nizam` — written manually, not committed.

Mirrors `command_allowlist` exactly. Without this, terminal commands in `command_allowlist` will fail with permission errors.

- [ ] **Step 1: Write sudoers rule**

```bash
sudo tee /etc/sudoers.d/admin-nizam <<'SUDOERS'
# Nazim (Hermes admin profile) — passwordless systemctl restart/start for defined services
# Generated for Phase 2. Edit command_allowlist in config/admin-config.yaml first, then update here.
Cmnd_Alias NIZAM_SERVICES = \
    /usr/bin/systemctl restart litellm-proxy, /usr/bin/systemctl start litellm-proxy, \
    /usr/bin/systemctl restart watcher-env, /usr/bin/systemctl start watcher-env, \
    /usr/bin/systemctl restart watcher-inventory.timer, /usr/bin/systemctl start watcher-inventory.timer, \
    /usr/bin/systemctl restart metrics-llm.timer, /usr/bin/systemctl start metrics-llm.timer, \
    /usr/bin/systemctl restart metrics-services.timer, /usr/bin/systemctl start metrics-services.timer, \
    /usr/bin/systemctl restart metrics-toolcalls.timer, /usr/bin/systemctl start metrics-toolcalls.timer, \
    /usr/bin/systemctl restart loki, /usr/bin/systemctl start loki, \
    /usr/bin/systemctl restart promtail, /usr/bin/systemctl start promtail, \
    /usr/bin/systemctl restart prometheus, /usr/bin/systemctl start prometheus, \
    /usr/bin/systemctl restart prometheus-node-exporter, /usr/bin/systemctl start prometheus-node-exporter, \
    /usr/bin/systemctl restart grafana-server, /usr/bin/systemctl start grafana-server, \
    /usr/bin/systemctl restart postgresql, /usr/bin/systemctl start postgresql, \
    /usr/bin/systemctl restart redis-server, /usr/bin/systemctl start redis-server
vazir ALL=(ALL) NOPASSWD: NIZAM_SERVICES
SUDOERS
sudo chmod 440 /etc/sudoers.d/admin-nizam
sudo visudo -c -f /etc/sudoers.d/admin-nizam   # → parsed OK
```
