# Pre-commit Hooks

Every project **MUST** have a `.pre-commit-config.yaml` at the repo root, installed via `pre-commit install`. Written by `scripts/write-precommit-config.sh` during `/scaffold` — not hand-authored or retyped from this file, since the content below never actually varies for a given stack combination. This file is the reference for _what_ and _why_; the script is what actually produces it. Covers:

## Python — ruff (lint + format)

Single-tool setup: ruff replaces flake8 + isort + black.

```yaml
- repo: https://github.com/astral-sh/ruff-pre-commit
  rev: <pinned-version>
  hooks:
    - id: ruff
      args: [--fix]
    - id: ruff-format
```

## Go — golangci-lint (lint + format)

```yaml
- repo: https://github.com/golangci/golangci-lint
  rev: <pinned-version>
  hooks:
    - id: golangci-lint
- repo: local
  hooks:
    - id: gofmt
      name: gofmt
      entry: gofmt -l -w
      language: system
      types: [go]
```

`golangci-lint`'s config (`.golangci.yml`) enables `revive`, `predeclared`, `misspell`, `errname` at minimum — these catch most of `go/code-style-naming.md`'s naming rules automatically.

## Next.js/TypeScript — Biome (lint + format)

Single-tool setup, same reasoning as ruff/golangci-lint: Biome replaces ESLint + Prettier.

```yaml
- repo: local
  hooks:
    - id: biome-check
      name: biome check
      entry: bunx biome check --write
      language: system
      types_or: [ts, tsx, javascript, jsx, json]
```

`biome.json` extends the Next.js/React recommended rule set. This is a real, not hypothetical, gap being closed here — a lint/format tool was missing from this file for the Next.js stack while Python and Go both had one.

## Hygiene — pre-commit-hooks

```yaml
- repo: https://github.com/pre-commit/pre-commit-hooks
  rev: <pinned-version>
  hooks:
    - id: trailing-whitespace
    - id: end-of-file-fixer
    - id: check-merge-conflict
    - id: check-added-large-files
```

## Rules

- Pin hook revisions (`rev:`) — no floating `main`/`HEAD` refs.
- Hooks run on every commit locally; CI re-runs the same checks so a skipped local hook (`--no-verify`) doesn't silently pass.
- Adding a new language/tool to a project requires adding its lint+format hooks here before code in that language merges to `qa`.
